# A2 生物笔记审查更改说明

本文档记录了对本目录下 A2 生物笔记进行内容审查后所做的全部修改。

## chp12.md（Respiration）

- 目录及标题拼写：`Oxygen Bebt` → `Oxygen Debt`；`Respiratory Substratess` → `Respiratory Substrates`
- 拼写：`Oxgyen` → `Oxygen`（2 处）、`fragnent` → `fragment`、`phosphorlylation` → `phosphorylation`、`spase` → `space`、`dose not` → `does not`、`methylene bule` → `methylene blue`
- 语法：`o produce` → `to produce`
- 去磷酸化相关语句改写，使表述通顺
- 笔误：`反而酶` → `的酶`
- Krebs 循环公式主体改正为 acetyl CoA，并添加 blockquote 说明（2 处）

## chp13.md（Photosynthesis）

- 术语/拼写改正：starch grains、metabolites、absorb the、chlorophyll b、separation、thylakoid、Calvin Cycle、catalyses the combination、indicates how、amino acid 等共 15 处
- 光反应公式改正为 NADP + 2e⁻ + H⁺ 形式
- Calvin cycle 物质平衡公式改写
- `5/6 of the TP molecules` 比例改正
- cyclic photophosphorylation（循环式光合磷酸化）解释重写
- photolysis（水的光解）关键词补充方程式

## chp14.md（Homeostasis）

- 拼写/术语改正共 15 处：dioxide、to form urea、three locations、GLUT4、GLUT2、conformation、peroxidase、hydrogen peroxide（3 处）、glucose、occurs、regions: proximal、phosphorylase kinase、Adenylyl cyclase、shrinks
- 肾单位中 afferent / efferent  arteriole 关系改正（afferent 比 efferent 粗）并改写解释
- ADH 作用"反之亦然"一句重写，使逻辑清晰

## chp15.md（Control and Coordination）

- 术语统一（replace_all）：Synapse / synapse / postsynaptic / cholinergic；sarcomere / sarcolemma / actin filament
- 静息电位 `-65mV` 添加注释说明
- 肌肉收缩表述改正：`ADP and Pi`、`transferred`、`tilts back`、`calcium ions bind`、`stimulated`、`a myofibril`、`A nerve cell`、`blood vessels`
- 捕蝇草部分改正：`leaf is divided into 2 lobes`、`does not trigger`、`lobes change`、`closure caused by` 句重写、`stimulated twice`
- 植物激素部分：活性形式注明为 GA₁；`GA₂₀` → `GA₁`；`LeLe or Lele` 基因型改正
- 中文笔误：`感知` 相关错字改正

## chp16.md（Inheritance）

- 改正：`does not involve`、`plural`、`crossing`（3 处）
- 计算改正：`2^23 = 8388608`
- monohybrid 存疑标注删除，改为正式注解
- `tyrosinase` 拼写改正（2 处）；白化症（albinism）相关语句重写
- `regulatory sequences` 添加注解
- lac operon 部分：`转录lacZYA` 表述改正（2 处）、`constitutive` 拼写改正
- 笔误：`控制主要发生在` 表述改正

## chp17.md（Selection and Evolution）

- `Hardy-Weinbery` → `Hardy-Weinberg`（全文 5 处，含目录、标题、正文）
- Hardy-Weinberg 公式说明改正：`$q$` 是**隐性**等位基因 a 的频率（原误写为 dominant）
- 拼写：`grnotypes` → `genotypes`、`priciple` → `principle`、`for man generations` → `for many generations`、`survivial` → `survival`、`prefect condtions` → `perfect conditions`
- Genome 定义补全缺失的粗体闭合标记：`**a cell or an organism**`

## chp18.md（Classification, Biodiversity and Conservation）

- 三域分类改正：Archaea 古生菌 描述由"介于植物和动物之间的活物"改为"原核生物，细胞结构类似细菌，但分子特征更接近真核生物"
- **Pearson 相关系数例题数据改正**（原数据与表格不符）：
  - $\bar{x}$：9.2 → 9.4（x 总和为 94）
  - $\sum xy$：2126 → 1966
  - $s_x$：2.10 → 2.59（2 处）
  - $n\bar{x}\bar{y}$：$10 \times 9.2 \times 20.4 = 2080.8$ → $10 \times 9.4 \times 20.4 = 1917.6$
  - 计算过程：分子 $1966 - 1917.6 = 48.4$，分母 $9 \times 2.59 \times 2.55 = 59.4$
  - 最终结果：$r = 0.896$ → $r = 0.815$
- 统计检验适用前提改正：
  - $\chi^2$ test：改正为适用于 **categoric / nominal**（定性、分类）数据（原误写为 quantitative）
  - Spearman's rank correlation：改正为适用于 **ordinal**（可排序）数据，或 continuous 但不满足正态分布的数据
- 笔误改正：`Species（个体）` → `（物种）`、`获取男性的精子` → `获取雄性的精子`
- 拼写：`membrane-bounmd` → `membrane-bound`、`quadrates` → `quadrats`、`smapling` → `sampling`、`specioes density` → `species density`、`mayt be` → `may be`、`上卖弄` → `上面`、`standard division` → `standard deviation`、`biodiversdity` → `biodiversity`、`adequatic` → `adequate`、`breedgin` → `breeding`、`二氧化然` → `二氧化碳`

- 凝胶电泳 marker 说明重写："可以通过与已知长度的片段（marker）对比，来估算未知DNA片段的长度。"
